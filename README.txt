DRYVEN website prototype

Open index.html in a modern browser.

Includes:
- Responsive driver dashboard inspired by the supplied screenshots
- Payments/history, payment entry, CSV export
- Vehicle register and add vehicle form
- Driver register and add driver form
- Admin/manager demo page and staff rows
- Reports and settings demo pages
- Admin/driver view switcher

Important:
This is a front-end prototype using sample data. Records are held in page memory and reset on reload.
It does not include secure login, a database, real bank/payment verification, notifications, or production role enforcement.
Before public launch, connect a backend/database and implement authentication, server-side role permissions, backups, and payment reconciliation. Replace sample bank accounts and names with verified, authorized details.
